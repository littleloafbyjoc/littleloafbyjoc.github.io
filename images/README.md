# Adding photos

Drop photos into this folder using the exact file names below. Each one
replaces its pink placeholder on the site automatically. No code changes needed.

| File name              | Where it shows                     | Best shape           |
| ---------------------- | ---------------------------------- | -------------------- |
| `hero.jpg`             | Top of the page, in the arch frame | Tall (4:5 portrait)  |
| `classic.jpg`          | Menu: classic sourdough            | Square               |
| `cinnamon-raisin.jpg`  | Menu: cinnamon raisin              | Square               |
| `jalapeno-cheddar.jpg` | Menu: jalapeño cheddar             | Square               |
| `custom.jpg`           | Menu: custom specialty loaves      | Square               |
| `jocelyn.jpg`          | About section, polaroid frame      | Tall (4:5 portrait)  |
| `gallery-1.jpg` to `gallery-6.jpg` | "Fresh from the oven" grid | Square          |

Tips:

- Photos are cropped to fit their frame, so keep the loaf near the middle.
- File names must match exactly, including lowercase and `.jpg`.
- Resize to about 1600px on the long side so the page loads fast on phones.
